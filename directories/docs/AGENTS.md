# AIcast Room 開発ルール・ガイドライン

**Version:** 1.0  
**作成日:** 2025-10-13  
**目的:** 開発品質の標準化と属人化防止

---

## 🎯 基本方針

AIcast Roomは**MCF（Mission Critical Functions）**を核とした外部連携重視のシステムです。すべての開発・運用は以下の原則に従います：

1. **MCF優先**: 外部連携（X API + Cloud Functions）を最優先で保護
2. **トレーサビリティ**: すべての変更は文書と連動
3. **テスト重視**: 外部連携は必ずテスト実行
4. **段階的実装**: 機能追加は段階的に実施

---

## 🔧 コミット前必須チェックリスト

### 📝 すべての変更（必須）
- [ ] **変更理由が明確**なコミットメッセージ
- [ ] **FEATURE_UPDATES_[日付].md**に詳細記録
- [ ] **影響範囲の確認**（MCF/非MCF）
- [ ] **動作確認**の実施

### 🎖️ MCF変更時（追加チェック）
- [ ] **MCF_DEFINITION.md**との整合性確認
- [ ] **外部連携テスト**の実行（X投稿は絵文字テスト）
- [ ] **バックアップ取得**（必要に応じて）
- [ ] **段階的デプロイ**の計画

## 📋 コミットメッセージ規約

### ✅ 良い例
```
fix: 投稿チューニング機能のVPS環境での反映問題を修正
feat: 一括予約機能の改修完了
docs: 機能仕様書に個別承認統一化と表示改善の追記
```

### ❌ 悪い例
```
修正
バグフィックス
更新
```

### 🏷️ プレフィックス規約
- `feat:` 新機能追加
- `fix:` バグ修正
- `docs:` 文書更新
- `refactor:` リファクタリング
- `test:` テスト関連
- `chore:` その他（設定変更等）

## 🎖️ MCF（Mission Critical Functions）定義

### 外部連携MCF
- **X API連携**: 投稿・リツイート・引用ツイート
- **Cloud Functions**: x-poster機能
- **認証システム**: API KEY管理
- **スケジューラー**: 自動投稿システム

### 保護すべき設定値
```python
_MCF_CLOUD_FUNCTIONS_URL = "https://asia-northeast1-aicast-472807.cloudfunctions.net/x-poster"
TEST_ACCOUNT_ID = "shinrepoto"
```

## 🔍 トラブルシューティング

### 外部連携エラー時
1. **認証状態確認**: Google Cloud認証・X API認証
2. **ネットワーク確認**: Cloud Functions疎通確認
3. **ログ確認**: エラーメッセージの分析
4. **テスト実行**: 絵文字テストでの動作確認

### 内部機能エラー時
1. **Geminiモデル確認**: バージョン・認証状態
2. **データベース確認**: 接続・データ整合性
3. **セッション状態確認**: Streamlitセッション
4. **設定値確認**: 環境変数・設定ファイル
