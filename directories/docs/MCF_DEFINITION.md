## 🎯 MCF概念定義

### Mission Critical Functions とは
**AIcast Roomにおいて絶対に死守すべき機能群**

1. **事業継続性**: サービス停止に直結する機能
2. **テスト困難性**: 外部依存により検証が困難
3. **影響範囲大**: 障害時の影響が広範囲
4. **復旧困難性**: 障害からの復旧に時間を要する

## 🌐 外部連携MCF（最重要）

### 1. X API連携システム
**優先度**: 🎖️ CRITICAL

#### 核心機能
- **投稿機能**: テキスト・画像投稿
- **リツイート機能**: 自動・手動リツイート
- **引用ツイート機能**: カスタムコメント付きリツイート
- **認証管理**: API KEY・トークン管理

#### 保護対象コンポーネント
```python
# 絶対保護すべき設定値
_MCF_CLOUD_FUNCTIONS_URL = "https://asia-northeast1-aicast-472807.cloudfunctions.net/x-poster"
TEST_ACCOUNT_ID = "shinrepoto"
```

#### MCF理由
- **外部依存**: X APIの仕様変更リスク
- **テスト困難**: 実際の投稿が必要
- **事業影響**: SNS発信停止は致命的
- **復旧困難**: API認証問題の解決に時間要

### 2. Cloud Functions連携
**優先度**: 🎖️ CRITICAL

#### 核心機能
- **x-poster Function**: X投稿の実行エンジン
- **HTTP通信**: アプリケーション⇔Cloud Functions
- **エラーハンドリング**: 失敗時の適切な処理
- **レスポンス処理**: 成功・失敗の判定

#### 保護対象ファイル
- `cloud_functions/x_poster/main.py`
- `x_api_poster.py`
- Cloud Functionsデプロイ設定

#### MCF理由
- **インフラ依存**: GCPサービス依存
- **デプロイ複雑**: 手動デプロイが必要
- **設定複雑**: 環境変数・権限設定
- **デバッグ困難**: ローカル実行不可

### 3. スケジューラーシステム
**優先度**: 🎖️ CRITICAL

#### 核心機能
- **自動投稿**: 指定時刻での投稿実行
- **リツイート自動化**: スケジュール化されたリツイート
- **cron実行**: 定期実行の仕組み
- **状態管理**: 実行状態の追跡

#### 保護対象ファイル
- `local_schedule_checker.py`
- `local_retweet_scheduler.py`
- cron設定・systemdサービス

#### MCF理由
- **時間依存**: タイミングが重要
- **自動実行**: 人の介入なしに動作
- **連鎖障害**: 一箇所の障害が全体に影響
- **監視困難**: 深夜・休日の動作

## 🧠 内部処理システム（準MCF）

### 1. AI連携システム
**優先度**: 🔶 HIGH

#### 核心機能
- **Google Cloud Vertex AI**: Geminiモデル連携
- **認証管理**: ADC（Application Default Credentials）
- **コンテンツ生成**: 投稿文・画像生成
- **プロンプト処理**: AIへの指示生成

#### 保護対象
- Google Cloud認証設定
- Geminiモデル設定・バージョン
- プロンプトテンプレート

#### 準MCF理由
- **比較的安定**: 認証・バージョン問題程度
- **回復可能**: エラー対応で解決可能
- **代替可能**: 手動入力での代替が可能

### 2. データベースシステム
**優先度**: 🔶 HIGH

#### 核心機能
- **SQLite**: `casting_office.db`
- **キャスト管理**: PERSONA_FIELDS管理
- **投稿履歴**: send_history管理
- **設定保存**: アプリケーション設定

#### 保護対象
- データベーススキーマ
- 重要テーブル（casts, posts, send_history）
- バックアップ・復旧手順
