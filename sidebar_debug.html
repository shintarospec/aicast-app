🔍 Streamlit Sidebar Debug Guide

📋 開発者ツールで確認すべき要素

  1. ブラウザでF12を押して開発者ツールを開く
  2. Elements/要素 タブを開く
  3. Ctrl+Fで以下を検索:
    • collapsedControl
    • stSidebarCollapseButton
    • stHeader
  4. 見つかった要素の:
    • display プロパティ
    • visibility プロパティ
    • opacity プロパティ
    • z-index プロパティ
    • position プロパティ
    を確認

🎯 よくある問題と解決策

問題1: ボタンが存在するが非表示

症状: DOMには存在するがdisplay: noneになっている

解決: CSSで!importantを使って強制表示

問題2: ボタンが他の要素の下に隠れている

症状: z-indexが低い、または親要素のoverflowで切り取られている

解決: z-index: 999999 !importantとposition: fixed !important

問題3: Streamlitバージョンによる挙動の違い

症状: 新しいバージョンでセレクタ名が変更された

解決: 複数のセレクタで対応（フォールバック）

🛠️ 診断用JavaScriptコード

ブラウザのコンソールで以下を実行:

// サイドバー開閉ボタンを全て検索
const buttons = document.querySelectorAll('[data-testid*="ollapse"], button[kind="header"]');
console.log('Found buttons:', buttons.length);
buttons.forEach((btn, i) => {
    const styles = window.getComputedStyle(btn);
    console.log(`Button ${i}:`, {
        display: styles.display,
        visibility: styles.visibility,
        opacity: styles.opacity,
        zIndex: styles.zIndex,
        position: styles.position
    });
});

💡 現在の対策

  • ✅ 複数セレクタでフォールバック対応
  • ✅ z-index を最大値に設定
  • ✅ position: fixed で確実に表示
  • ✅ ヘッダー内の全要素を表示
